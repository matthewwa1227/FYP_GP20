# StudyQuest - StoryQuest System Documentation

## Overview

**StoryQuest** is an RPG-style gamified learning module within StudyQuest. It transforms traditional study sessions into epic adventures where students become heroes battling the "Shadow of Ignorance" through mastering academic topics.

---

## How StoryQuest Works

### 1. Entry Point
- **Route**: `/story-quest`
- **Component**: `frontend/src/components/AITutor/StoryQuestAI.jsx`
- **Backend Routes**: 
  - `/api/storyquest/*` (storyquest.js)
  - `/api/ai/story/*` (aiStory.js)

### 2. Topic Selection Flow

```
Student enters topic (e.g., "Mathematics", "History", "Python")
         ↓
System selects THEME based on topic keywords
         ↓
AI generates CHAPTER SCHEDULE (4 chapters)
         ↓
Student views quest schedule and clicks "BEGIN"
```

### 4. Chapter Structure

Each quest consists of **4 chapters** generated by AI:

```
Chapter 1: The Beginning (Foundation Concepts) - 15 min
Chapter 2: First Steps (Core Principles) - 20 min  
Chapter 3: The Challenge (Advanced Application) - 25 min
Chapter 4: Mastery (Expert Level + Boss Battle) - 30 min
```

### 5. Learning Flow Per Chapter

```
┌─────────────────────────────────────────────────────────┐
│  CHAPTER START                                          │
│  └─> AI-generated story scene sets the context          │
│                                                         │
│  LEARN SCENE                                            │
│  └─> Structured lesson content with:                    │
│      • KEY POINTS (bullet points)                       │
│      • FULL LESSON (detailed explanation)               │
│      • WHY IT MATTERS (real-world relevance)            │
│                                                         │
│  PRACTICE QUESTION                                      │
│  └─> AI-generated multiple choice question              │
│      • 4 choices (A, B, C, D)                           │
│      • Immediate feedback                               │
│      • Explanation of correct answer                    │
│      • +XP reward on success                            │
│                                                         │
│  NEXT CHAPTER / BOSS BATTLE                             │
└─────────────────────────────────────────────────────────┘
```

### 6. Boss Battle System (Chapter 4)

The final chapter includes a **Boss Battle** with 3 consecutive questions:

- Questions are generated based on the lesson content from all chapters
- Students must answer all 3 correctly to "defeat the boss"
- No XP penalty for wrong answers (encourages learning)
- Victory unlocks completion and rewards

### 7. AI Integration

**Service**: `kimiService.js` (backend)

#### API Endpoints:

```javascript
// Generate story intro
POST /api/storyquest/intro
Body: { topic: string }

// Generate scene narrative
POST /api/storyquest/scene
Body: { topic, chapter, sceneType, context }

// Generate lesson content
POST /api/storyquest/lesson
Body: { topic, chapter, conceptNumber }

// Generate practice question
POST /api/storyquest/question
Body: { 
  topic, 
  subject, 
  chapterTitle, 
  difficulty, 
  lessonContent,
  isBoss: boolean 
}

// Generate boss questions (3 questions)
POST /api/storyquest/boss-questions
Body: { lessonContent, subject, chapterTitle }
```

### 11. Data Flow Example

```
Student: "I want to learn about Fractions"

1. Frontend: POST /api/ai/story/schedule { topic: "Fractions" }
2. Backend: Kimi AI generates 4 chapters
3. Frontend: Displays ScheduleScreen with chapters
4. Student: Clicks "BEGIN YOUR QUEST"
5. Frontend: POST /api/storyquest/lesson { topic: "Fractions", chapter: 1 }
6. Backend: Returns structured lesson with KEY POINTS, FULL LESSON, WHY IT MATTERS
7. Frontend: Displays LearnScene
8. Student: Clicks "CONTINUE TO PRACTICE"
9. Frontend: POST /api/storyquest/question { ... }
10. Backend: Returns multiple choice question
11. Frontend: Displays question, student answers
12. [Loop continues through all 4 chapters]
13. Chapter 4: Boss battle with 3 questions
14. Victory: Show completion screen with XP rewards
```

### 12. Progress Persistence

Currently, StoryQuest progress is **session-based** (not persisted to database). Future enhancements could include:
- Saving quest progress to `student_progress` table
- Tracking completed topics
- Unlocking achievements
- Continuing interrupted quests

## Rebuilding StoryQuest - Recommendations

### Architecture Improvements:
1. **State Management**: Use React Context or Redux for quest state
2. **Progress Persistence**: Save to database via `/api/progress` endpoints
3. **Question Bank**: Cache generated questions to reduce AI costs
4. **Offline Support**: Allow offline practice with cached content
5. **Multiplayer**: Team-based boss battles

### UI Enhancements:
1. **Animated Transitions**: Page transitions between chapters
2. **Character Customization**: Let students choose hero avatar
3. **Inventory System**: Unlock weapons/items by completing quests
4. **Boss Animations**: Visual boss health bar and attack animations
5. **Sound Effects**: Retro 8-bit sounds for actions

### Educational Enhancements:
1. **Adaptive Difficulty**: Adjust based on student performance
2. **Spaced Repetition**: Review previous quest content
3. **Peer Comparison**: How did other students do on this quest?
4. **Teacher Dashboard**: View student quest progress

---

## Current Limitations

1. **No Save/Resume**: Quests must be completed in one session
2. **AI Latency**: Question generation takes 5-15 seconds
3. **Content Filter**: Sometimes blocks valid questions
4. **Mobile UX**: Not optimized for small screens
5. **No Audio**: No narration or sound effects
